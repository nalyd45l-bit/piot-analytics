# Google Apps Script — что есть и чего не хватает

`Code.gs.example` — оболочка запуска: добавляет меню «Панель PIOT», открывает HTML-файл `Index` и предоставляет `doGet()`.

Это **не** готовый серверный API и не подключение к таблице. Клиентская часть ожидает серверные методы:

- `apiGetData()` — чтение записей, месячного реестра и настроек;
- `apiSaveMonth(arg)` — проверенное сохранение месячных показателей;
- `apiSaveConfig(arg)` — проверенное сохранение настроек.

В исходниках, переданных в этот чат, реализации этих серверных методов и точной схемы листов нет. Поэтому демо на GitHub Pages не пишет в настоящую Google Sheets.

Для интеграции потребуются существующий серверный `Code.gs` или описание листов и колонок. Нужно также адаптировать `index.html` для Apps Script HtmlService: сейчас он подключает отдельные CSS/JS-файлы относительными ссылками, которые подходят для статического сайта.
