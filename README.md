# ТС ПИОТ · Аналитика

Клиентская часть аналитической панели, расчётная модель и демонстрационный адаптер.

## Состав

- `index.html` — страница приложения.
- `styles.css` — стили интерфейса.
- `app.js` — интерфейс, навигация, графики, фильтры и обработка действий.
- `piot.js` — расчёты, фильтрация, классификация заявок, валидация и CSV.
- `demo.js` — синтетические демонстрационные записи и имитация API.
- `tests/piot.test.js` и `tests/demo.test.js` — автоматические проверки расчётного модуля и демонстрационного API.
- `apps-script/Code.gs.example` — пример меню и запуска панели из Google Sheets; это не серверный API.

## Локальный просмотр / GitHub Pages

Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages. Страница запускается в демонстрационном режиме: `demo.js` создаёт случайные тестовые записи, не реальные клиентские данные.

## Подключение Google Sheets

`app.js` ожидает серверные функции Google Apps Script:

- `apiGetData`
- `apiSaveMonth`
- `apiSaveConfig`

Файл `apps-script/Code.gs.example` содержит только меню и точку запуска `doGet()`; функций `apiGetData`, `apiSaveMonth` и `apiSaveConfig` в исходниках нет. Поэтому GitHub Pages показывает демоверсию; чтение и запись реальной Google-таблицы пока не подключены и не проверены. Для production-развёртывания необходимо добавить серверный API Apps Script и проверить его схему листов и права доступа. Сам пример `Code.gs` нельзя считать готовой интеграцией.

## Проверка расчётного модуля

Требуется Node.js 18+:

```bash
npm test
```

## Безопасность

В репозиторий не включены выгрузки клиентских данных, токены или пароли. Не добавляйте реальные данные клиентов, секреты и идентификаторы доступа в публичный репозиторий.
